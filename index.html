Tentang Saya

Saya lulusan S1 Teknik Informatika dari Universitas Informatika dan Bisnis Indonesia (UNIBI) dengan IPK 3.65 dan minat kuat di Software Engineering, khususnya Web Development. Saya memiliki pengalaman membangun aplikasi web full stack menggunakan PHP, Laravel, JavaScript, HTML, CSS, MySQL, dan RESTful API.

Selama magang sebagai Web Programmer di Pengadilan Negeri Bale Bandung, saya mengembangkan Layung Peradilan — sistem administrasi peradilan terintegrasi dengan layanan Disdukcapil (Cimahi, Kabupaten Bandung, dan Bandung Barat) untuk verifikasi data warga secara otomatis. Pengembangan mencakup requirement gathering, perancangan database & alur sistem, pengembangan front-end/back-end, integrasi API, deployment, hingga maintenance.
